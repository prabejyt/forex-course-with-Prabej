TRADE WITH PRABEJ — COMPLETE FINAL
=====================================

Open index.html. The entire academy is in this single HTML file, including the 30 chart visuals embedded as data URIs.

Features:
- Cinematic 3D login/signup
- Local demo account
- Home dashboard
- 30 visual chapters
- Chapter search + level filter
- Direct chart images on every chapter card
- Large chart inside lesson
- Progress tracking
- Practice quiz
- Completion certificate page
- Responsive mobile/desktop design

Important:
This is a static educational demo. Authentication is localStorage-based and is NOT suitable for storing real passwords or production user accounts. For production, connect a secure backend/auth provider.

Publishing:
1. Extract the ZIP.
2. Upload index.html and the assets folder if you want the backup images.
3. The embedded images mean index.html can display charts without relying on the assets folder.
